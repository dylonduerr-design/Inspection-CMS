# 📱 Offline Mode Quick Start Guide

## What is Offline Mode?

Work anywhere, even without internet! Create reports, fill checklists, take notes, and attach photos. Everything syncs automatically when you're back online.

## 🚀 Getting Started (2 Minutes)

### Option 1: Install as App (Recommended)

**On Phone:**
1. Open site in browser
2. Tap "Install App" or "Add to Home Screen"
3. App appears on your home screen
4. Launch like any other app

**On Computer:**
1. Look for install icon in address bar 🖥️
2. Or click "📱 Install App" button
3. App opens in its own window

### Option 2: Use in Browser
Just use the site normally - offline features work automatically!

## 📝 Working Offline

### Creating a Report

1. Fill out the form as usual
2. Look for the offline indicator (top right):
   - 🟢 Green = Online
   - 🔴 Red = Offline
3. Click **"💾 Save Offline"** button
4. Report saved locally, will sync automatically

### What Works Offline?

✅ **YES - Full Functionality**
- Create new reports
- Fill all form fields
- Complete checklists
- Add notes/observations
- Attach photos
- Auto-save drafts

❌ **NO - Needs Internet**
- AI Assistant
- Export to Word/PDF
- Real-time updates
- Uploading to server

## 🔄 Syncing Your Data

### Automatic Sync
When internet returns, your offline reports sync automatically! You'll see a notification.

### Manual Sync
Click **"🔄 Sync Now"** button to sync immediately.

### Checking Pending Syncs
Look at the offline indicator - the number badge shows pending reports.

## 💡 Pro Tips

**Auto-Save is Your Friend**
- Forms save automatically every 2 seconds
- Close browser? Your work is safe!
- Come back later? Your draft is waiting

**Photo Strategy**
- Take photos offline
- They'll upload when online
- Check storage if having issues

**Before Going Offline**
- Load the pages you'll need while online
- They'll be cached for offline use

**Managing Storage**
- Browser stores your data safely
- Sync regularly to free up space
- Old drafts clean up automatically

## 🆘 Troubleshooting

**"Offline save not working"**
→ Check browser console (F12) for errors
→ Try refreshing the page
→ Check browser storage permissions

**"Sync button does nothing"**
→ Make sure you're online (check indicator)
→ Try waiting a moment and clicking again
→ Check browser console for errors

**"Running out of storage"**
→ Sync pending reports to server
→ Browser allows 1-2GB typically
→ Clear old cached photos if needed

**"Can't install app"**
→ Use Chrome, Edge, or Safari
→ Ensure you're on HTTPS (or localhost)
→ Try the browser menu instead

## 📊 Understanding the Interface

### Offline Indicator (Top Right)
```
🟢 Online         = Connected, syncing works
🔴 Offline        = No connection, saving locally
🟢 Online [3]     = 3 reports waiting to sync
```

### Form Buttons
```
Save & Submit     = Regular save (needs internet)
💾 Save Offline  = Save locally (works offline)
🔄 Sync Now      = Upload pending reports
```

### Status Messages
```
Green  = Success! Everything is good
Yellow = Warning or info
Red    = Error, check your connection
Blue   = Information
```

## 🎯 Best Practices

### For Field Inspectors

1. **Install the app** on your phone
2. **Load the site once** while online (caches essentials)
3. **Work normally** - offline mode is automatic
4. **Sync when possible** - don't wait too long
5. **Check the badge** - know how many are pending

### For Office Use

2. **Regular save** works fine when online
3. **Offline save** as backup if connection unstable
4. **Manual sync** if auto-sync seems slow

## 🔐 Privacy & Security

- Data stored only on your device
- Not shared between devices
- Syncs only to your account
- Clear browser data = deletes local copies

## ❓ Quick FAQ

**Q: Do I need to install the app?**
A: No, but it's nicer! Works in browser too.

**Q: How much data can I store?**
A: Typically 1-2GB, enough for hundreds of reports.

**Q: What if I lose my device?**
A: Only synced reports are on the server. Unsynced reports are lost.

**Q: Can I work on multiple devices?**
A: Each device stores its own offline data. Sync to share between devices.

**Q: Does this use my data plan?**
A: Only when syncing. Offline work uses zero data.

**Q: How do I uninstall?**
A: Phone: Hold icon → Remove App
   Computer: App menu → Uninstall
